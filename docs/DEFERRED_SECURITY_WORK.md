# Отложенные задачи по безопасности SwimCRM

Решения, отложенные владельцем продукта 2026-11-11. Этот список не означает,
что риски устранены.

1. **Анонимизация.** Определить сроки хранения финансовых фактов и очистить
   персональные данные из свободного текста платежей, начислений, посещений,
   уведомлений и исходных имён файлов квитанций. Сейчас этот риск оставлен.
2. **Импорт XLSX.** До чтения таблицы ограничить распакованный размер XML и
   shared strings, чтобы маленький архив не исчерпал память процесса.
3. **Интеграции через CRM.** Сделать одну общую почту Gmail с подключением через
   Google, одного бота Telegram и одного SMS-провайдера. Подключать и менять
   интеграции может только главный администратор; остальные видят состояние.
   Gmail потребует разовой настройки OAuth-приложения Google. До реализации
   этого пункта явно настроенная серверная почта продолжает работать, а
   неработающая в production получает статус ошибки; SMS и Telegram в
   production допускают только HTTPS.
4. **Обязательная 2FA для всех администраторов.** Сейчас TOTP добровольна до
   личной привязки. Позже продумать порядок перехода к обязательной 2FA без
   потери доступа действующих и новых администраторов.

Открыто перед выпуском: установить фактический путь резервных копий на рабочем
сервере и проверить права каталога и файлов. Инструкция есть в `OPERATIONS.md`;
автоматическая проверка прав не выбрана.
